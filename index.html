手机 / 平板怎么用

📐 屏幕
已自动适配手机和平板：竖屏单栏、平板更宽、横屏自动压缩留白，刘海屏和底部小黑条也留了安全距离。用浏览器「添加到主屏幕」后就是全屏 App 的样子。
🖼 从相册选图片
点带 🖼 的按钮，手机会弹出「照片图库 / 相册」，选一张就行。头像和背景还专门拆成三个按钮：🖼 从相册选、📁 从文件里选、📷 拍照。
微信 / QQ 里的图片，先在聊天里长按「保存到相册」，再回来从相册选。
📁 拿微信 / QQ 里的文件
网页不能直接读微信、QQ 自己的文件夹——这是手机系统的应用隔离，任何网页都做不到，不是青笺的限制。绕过去只要一步：
① 在微信 / QQ 里长按文件 →「用其他应用打开」/「保存到手机」/「存储到文件」→ 存进系统「文件」（iPhone）或「下载 / Download」（安卓）；
② 回青笺点「📁 导入文件」（语料库）或「📁 从文件里选」（背景、头像）；
③ 在弹出的选择器里点「浏览 / 文件」，找到刚存的文件。
iPhone 通常在「文件 → 我的 iPhone / iCloud 云盘 / 下载」，安卓通常在「下载 / Download」。
✍️ 纯文字语料最快的办法
在微信 / QQ 里长按消息「复制」，回语料库点「粘贴导入」贴进来，一行一句。不用管文件格式和编码，最不容易乱码。
🔒 数据存在哪 · 怎么换设备
语料、聊天、信件、测试、图片只存在这台设备的浏览器里，不上传服务器。换手机或换平板：在旧设备点「设置 → 导出与备份 → 📦 导出全部数据」，把 .json 存进「文件 / 下载」或发给自己；新设备打开青笺后点「📥 导入备份 / 还原」选这个文件即可。导入只追加不覆盖，背景、头像、昵称、开关每台设备各自保留。
